Perguntas Frequentes

Como funciona a demonstração?

O fluxo apresenta um formulário, uma animação de preparação e este painel com dados fictícios. Os componentes podem ser usados como base visual do seu projeto.

Meus dados são enviados para algum lugar?

Não. Não há chamadas de API, rastreamento ou conexão com contas externas. As imagens e os áudios estão incluídos na pasta do projeto.

Preciso instalar alguma coisa?

Não. Basta abrir index.html em um navegador moderno. Para desenvolver, você também pode usar um servidor estático local.

Como funciona a área de planos?

O preço e os benefícios são exemplos de layout. O botão abre uma explicação e não inicia compra, cobrança ou cadastro.

Posso personalizar as telas?

Sim. Edite os arquivos HTML para alterar os textos e a estrutura, styles.css para o visual e app.js para as interações.
