Parâmetros usados no download: `w=640&q=85&fit=crop`.

`mapa.svg` e `favicon.svg` são vetores criados para esta interface. O mapa é fictício e não utiliza dados do Google Maps.

`audio-1.wav` a `audio-4.wav` contêm sequências sintéticas de três notas, com três segundos de duração; não são falas nem gravações de pessoas.

Os ícones de interface são caminhos SVG simples incluídos no próprio JavaScript. A tipografia usa fontes do sistema. Não há imagens íntimas, fotografias borradas ou arquivos extraídos do servidor comprometido.
