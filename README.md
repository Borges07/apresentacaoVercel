# Apresentação Vercel

Demonstração estática com quatro páginas em HTML, CSS e JavaScript. Os arquivos originais ficam em `projeto-recuperado/`.

## Prévia local

```sh
node preview.cjs
```

Abra http://localhost:8080. Rotas: `/`, `/acesso`, `/processando` e `/painel`.

## Vercel

Importe este repositório com Framework Preset **Other** e Root Directory na raiz. `vercel.json` configura a pasta de saída e as URLs sem extensão. Não há build nem variáveis de ambiente.

Veja [PUBLICAR-NA-VERCEL.md](PUBLICAR-NA-VERCEL.md) para instruções e roteiro da apresentação. Dados e interações são demonstrativos.
